## Project Structure

- `lib/`: Contains the Dart code for the application.
  - `main.dart`: Entry point of the app.
  - `screens/`: UI screens.
  - `widgets/`: Reusable widgets.
  - `models/`: Data models.
  - `services/`: API and service layers.

## Dependencies

See `pubspec.yaml` for the list of dependencies.

## Running the App

1. Ensure you have Flutter installed. Follow the installation guide: https://flutter.dev/docs/get-started/install
2. Run `flutter pub get` to install dependencies.
3. Connect a device or start an emulator.
4. Run `flutter run`.
